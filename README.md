# BuildLock Flutter UI Prototype

A premium construction-material sourcing and fulfilment marketplace UI prototype.

## Included flows
- Splash / Welcome / Role selection / Login / OTP
- Contractor home, project selector, material search, categories, material details
- Nearby suppliers list + map-style view
- Supplier detail + direct request
- Broadcast requirement + live broadcast status
- Quote comparison + quote detail
- Order agreement + digital signature UI + payment
- Locked order + order timeline + delivery tracking
- Delivery verification + issue reporting + POD + completion
- Contractor profile, payments, documents, notifications, disputes
- Supplier dashboard, requests, quote, inventory, order preparation, dispatch, earnings
- Admin dashboard and monitoring UI

## Notes
- This is a UI-first prototype with mock data.
- No real payment, GPS, digital-signature certificate, notifications, API or backend is connected.
- Flutter SDK was not available in the build environment, so the project was generated as source and not compiled here.

## Run
```bash
flutter pub get
flutter run
```
